# Local Fastlane development

Work in this checkout on `fix/clearer-planner-and-sidebar`. Preserve existing features and security checks. Origin is SimpSlader/Longhorn-Fastlane-Plus; upstream is fetch-only and must never receive pushes.

Use the project-local Node/pnpm toolchain configured in `update-fastlane.sh`. After requested source changes run `./update-fastlane.sh --local`: it installs locked dependencies, checks types and style, runs unit tests, builds, runs security and browser tests, and synchronizes the verified existing Chrome installation. Use `./update-fastlane.sh` to fetch and update the branch first. Never discard uncommitted changes; resolve conflicts while retaining Git's autostash.

Machine-specific settings live in the git-ignored `fastlane.local.json` (copy `fastlane.local.example.json`): repository path, branch, toolchain `bin` folder, the unpacked extension folder Chrome loads, the Chrome profile folder, the extension ID, and the backup folder. Never commit that file or copy its values into tracked files, docs, tests or commit messages. Keep the configured extension folder and manifest identity unchanged. Never uninstall the extension, reset Chrome storage, or copy test fixtures to the user's profile. Sync only with `scripts/local/sync-extension.py`, which verifies the configured folder against Chrome preferences, backs up files, copies without deletion, and verifies hashes. If permissions prevent syncing, request access to that exact folder. Do not weaken permissions, CSP, privacy checks, or registration safeguards.

Browser tests use separate temporary profiles; never launch Playwright against the real Chrome profile. Local builds made by `update-fastlane.sh` include a self-reload helper (`src/fastlane/background/devAutoReload.ts`, flag `VITE_FASTLANE_DEV_AUTORELOAD`): the sync script writes `fastlane-dev-build.json` last, and the extension reloads itself within ~30 s or when a UT/Fastlane page opens (never twice to the same build, at most once a minute, and it waits with an "Install now" notification while a UT registration tab is open). Stale UT tabs stop Fastlane work and show a refresh notice via `src/fastlane/services/extensionContext.ts`; never auto-refresh UT pages. Store packages must be built with plain `pnpm build` (package.mjs refuses a local build). If the installed copy predates the helper, tell the user to click Reload once at chrome://extensions; do not claim the user's saved schedules were verified unless actually observed. JSON backup is available in Fastlane Settings → Your data → Include degree audit → Export schedules & plans (JSON).
